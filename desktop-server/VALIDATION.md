## 实际播放

- 原生预览：从首页搜索 `TV`，确认选片，经 8090 电脑服务播放合成 HLS；Media3 实际渲染 1280×720，`route=desktop`，无播放错误。服务端出现播放列表和分片流量。
- 遥控器回归：下键呼出控制栏、左右移动焦点、快进预览与确认/返回取消、倍速、完整显示/裁切、上键选集、正倒序与焦点归还均通过，测试完成恢复现场。
- 原生预览切换 HLS / MP4：画面实际渲染，旧会话删除，服务端 `activeSessions=1`。
- 原生预览断线：停掉电脑串流服务，跳转至尚未缓冲的 150 秒，出现「重试电脑串流 / 切回独立直连」。用遥控器下键、确认切回，仍在原影片附近进度继续渲染 720P，电脑服务处于关闭状态。
- 默认旧界面：片源管理中选择电脑串流并测试连接成功；首页搜索、选片、HLS/MP4 播放输出 720P，副标题注明未启用超分。
- 默认旧界面断线：停掉电脑服务，跳转至 60 秒触发错误；焦点自动位于重试按钮，右键、确认切回独立直连，恢复在约 61 秒，720P 实际渲染且错误面板消失。
- 公网 HTTPS：通过本机代理 Fake-IP 模式转发公共测试页面成功；本机 DNS 的 198.18.0.0/15 兼容需要显式参数，仍拒绝直接指定该 IP 和普通私网片源。

断线验证使用 CDP 跳转到未缓冲位置来触发实际网络请求；模式切换使用真实 ADB 遥控器按键。界面状态与渲染标记用于判断，未把 API 请求成功等同于视频播放成功。测试片源 8091 独立于电脑串流服务 8090，故关闭 8090 后的直连恢复不依赖电脑中转。

## 0.4.3 搜索缓存与超分开关 · 2026-10-23

设备新增有界持久化缓存：每源搜索成功 10 分钟、失败 30 秒；换源可用性/集数结论 5 分钟，过期先显示缓存再后台刷新，最多保留 24 小时。来源身份、启用集合和过滤规则参与缓存键；刷新来源绕过缓存，实际播放地址仍短期缓存。未知画质和失败结论尊重已有 TTL，避免每次展开重复探测。原生面板重复更新保留按钮对象、选择和焦点。搜索批次完成时主动落盘，修复立即强制退出时最后两条画质未保存的问题。
